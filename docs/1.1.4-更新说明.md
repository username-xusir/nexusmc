# NEXMC 1.1.4 更新说明

1.1.4 修复更新弹窗标题重叠，并补上 1.1.4 更新横幅。夸克 412 修复和更新检查缓存继续保留。

## 修复标题重叠

更新弹窗里原本是：

```text
发现新版本 1.1.3
```

但 Release 标题和版本标题被放在了同一个 Grid 行，标题开头的“NEXMC”会叠到“发现新版本”的第一个字上，看起来像多了一个小字。

现在：

- “发现新版本”在独立第 0 行；
- Release 标题在独立第 1 行；
- 两行不再重叠。

## 1.1.4 横幅

新增：

```text
assets/updates/1.1.4.png
assets/updates/1.1.4-dark.png
assets/updates/1.1.4-white.png
```

更新弹窗会优先加载本地 `1.1.4-dark.png`，找不到时再加载 `1.1.4.png`，最后才使用内置渐变兜底。

## 保留的修复

- 夸克 `file/download` 响应里的全部 `Set-Cookie` 会合并到下载请求，修复 412。
- 更新检查有 10 分钟缓存、ETag 条件请求和 403 / 429 恢复时间提示。
- 保留 1.1.1 的字体、启动器停用、自动 / 256 线程和界面布局修正。

## 验证

- 单元测试：79/79 通过。
- 1.1.4 安装包干净安装启动显示 1.1.4，卸载后安装目录完全删除。
- 更新弹窗标题已分行，1.1.4 横幅资源随安装包分发。
