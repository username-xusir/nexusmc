# NEXMC 1.0.10 更新说明
1.0.10 是 1.0.9 的 Windows 10 兼容补丁，重点修复图标字体和默认浏览器缺失问题。

更新日期：2026-11-13

## 国内镜像卡住

- 复现环境：Minecraft `26.3` 正式版、`26.4-snapshot-6` 快照，设置「国内镜像」。
- 根因：BMCLAPI 对 `26.x` 不是直接缓存文件，而是把每个文件 302 重定向到不同的第三方 CDN；5,000 多个资源逐个跳转后，安装会长时间停在 60% 左右。部分路径还会直接 404。
- 修复：`26.x` 这类年份版本号直接使用官方源安装，不再走逐文件跳转的镜像；安装结束后恢复用户原来的线路设置。旧版本仍保留镜像探测和失败回退。
- 同时修复大文件下载期间百分比长时间不变被误判为卡死：看门狗现在同时检查下载缓存字节数，只有真正没有数据流动才中断。
- 镜像连续无响应时，重试阶段自动切换官方源，不再重复同一条卡住线路。

## 点击下载后界面卡死

- 根因：安装入口里有同步的设置锁、目录创建和版本目录扫描，过去直接在 UI 线程执行；网络盘、移动盘或后台元数据请求占用锁时，主窗口会整段无响应。
- 修复：内核安装入口整体移到后台线程；仅下载模式的目录创建、整合包同名检查也移到后台。
- 安装完成结果窗口改为非模态，主界面不会被结果窗口锁住。
- 命名整合包、BBSMC 验证、添加启动器、名人堂等窗口改为屏幕居中，避免窗口跑到屏幕外造成“看起来卡死”。

## BBSMC 验证后不安装

- 根因：验证窗口下载完成后，原来的在线安装任务已经失败；旧逻辑只把文件设为本地包，没有自动继续安装。
- 修复：验证窗口返回下载文件后，自动用本地文件补装失败的目标；全部目标都失败时复用原任务，状态从「失败」变为「验证通过，正在重新安装…」，成功后显示对勾；如果只有部分启动器失败，则新建一个只包含失败目标的任务。
- 「仅下载到本地」模式会直接把验证窗口下载的文件复制到设置的保存目录。

## 整合包列表滚动位置

- 从整合包版本页点「返回整合包列表」时，恢复进入版本页前的列表滚动位置，不再回到顶部。

## Windows 10 图标与浏览器

- Windows 10 没有 Segoe Fluent Icons，图标字体自动回退到 Segoe MDL2 Assets；已验证导航、整合包、设置、下载、勾选、窗口按钮等全部字形都存在。
- 系统默认浏览器被删除、卸载或关联损坏时，打开项目页/网盘/鸣谢链接会自动进入 NEXMC 内置浏览器。
- BBSMC 的项目页、版本页和验证流程默认使用内置浏览器，不依赖系统默认浏览器。
- 内置浏览器优先使用 WebView2；WebView2 也不可用时，退回系统兼容浏览器并把链接复制到剪贴板。
- BBSMC 验证窗口同样增加兼容浏览器兜底：WebView2 初始化失败时先尝试系统兼容浏览器，仍失败才提示外部打开。

## 验证结果

- 单元测试：59/59 通过。
- 国内镜像 `26.3`：识别为年份版本，自动使用官方源；安装 100%，校验通过，`MIRROR_OK source=mirror version=26.3 service=True`。
- 国内镜像 `26.4-snapshot-6`：识别为年份版本，自动使用官方源；安装 100%，校验通过，`MIRROR_OK source=mirror version=26.4-snapshot-6 service=True`。
- BBSMC 验证窗口下载的 `FarmingTales_ForgeⅡ v1.5.2_beta3.mrpack`：通过本地包安装路径完成安装，校验通过，`BBSMC_LOCAL_OK`（验证后自动续装使用同一条路径）。
- 新增 `InstallRetryRequestFactoryTests`：验证只重试失败目标、保留仅下载模式、清除在线项目/版本 ID。
- 列表滚动位置：UI Automation 实测同一个整合包在进入版本页前后 Y 坐标均为 707，输出 `SCROLL_OK`。
- 点击下载响应：UI Automation 选择 `26.4-snapshot-6`、设置国内镜像并点击安装；安装期间每 3 秒采样均为 `RESPONDING=True`、`MAIN_ENABLED=True`，26.4 安装完成后主窗口仍可操作。
- 安装包：静默安装到干净临时目录，启动显示 1.0.10，卸载后目录文件数为 0。
- PCL + HMCL 双目标回归：1.12.2 安装 100%，两个目标均校验通过，`DUAL_OK`。
- Fabric 1.20.1 回归：安装 100%，`FABRIC_OK`。
- Windows 10 字体回退：检查 `segmdl2.ttf`，本次使用的 12 个符号码点全部存在。
- 默认浏览器缺失路径：强制内置浏览器后，链接进入内置浏览器并显示“页面已加载”。

## 已知限制

- BBSMC 的真实人机验证必须由用户本人在内置 WebView2 窗口完成；自动化测试只覆盖验证完成后的本地包安装与请求构造。
- 国内镜像是否可用取决于 BMCLAPI 是否已同步对应版本；未同步时 NEXMC 会自动走官方源。
- 安装包未代码签名。
