# NEXMC 1.1.5 更新说明

1.1.5 是一次纯界面更新：换成接近参考图的深色配色和更圆的控件形状，按钮位置、页面排版和功能都不变。

## 配色

| 元素 | 颜色 |
|---|---|
| 页面背景 | `#090909` |
| 卡片 | `#151515` |
| 卡片边框 | `#2A2A2A` |
| 输入框 / 下拉框 | `#171717` |
| 主按钮 | `#2A2A2A` |
| 主文字 | `#F2F2F2` |
| 次要文字 | `#9A9A9A` |
| 强调色 | `#E8E8E8` |

原来的蓝色强调改成了黑白灰；成功和错误状态保留低饱和绿色和红色。

## 形状

- 卡片、顶部标题区、按钮、输入框、下拉框、弹出菜单、列表项统一使用 **CornerRadius 18**。
- 头像和圆形空状态保持圆形，这是圆形而不是圆角。
- 卡片和标题区不再使用淡色描边，改为黑色柔和阴影。
- 滚动条改为细的圆角滑块，不再出现直角方块。
- 按钮位置、尺寸和页面排版保持不变。

## 没有改什么

- 所有按钮的位置、宽度、高度和页面排版保持原样。
- 没有增删功能，没有改下载逻辑。
- 仅调整颜色、边框、圆角、下拉框模板和任务页背景。

## 深色弹窗

- 更新窗口、添加启动器、整合包命名、名人堂、登录窗口、安装完成窗口、内核连接窗口同步换色。
- 更新窗口的横幅渐变从“黑到白”改为“黑到深色页面”，避免深色主题下出现一条白边。
- 下载任务空状态页原来会露出一块白色背景，现在使用深色页面背景。

## 验证

- 单元测试：79/79 通过。
- 游戏下载、整合包、下载任务、设置四个页面截图检查通过。
- 顶部启动器下拉框、版本分类下拉框已改为深色模板。
- 按钮位置与 1.1.4 对比未移动。
- 安装包干净安装启动显示 1.1.5，卸载后安装目录完全删除。
