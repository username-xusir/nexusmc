# NEXMC 1.1.6 更新说明

1.1.6 修复“从 1.1.4 升级到 1.1.5 时看不到 1.1.5 横幅”的问题。

## 原因

1.1.4 客户端本地只有 1.1.4 及更早的横幅，没有 `1.1.5-dark.png`；更新窗口会去 Release 附件里找 `banner-dark.png`，但 v1.1.5 Release 当时只上传了安装包和 SHA-256，没有上传横幅，所以只能显示内置渐变。

## 修复

更新检查现在有两层横幅来源：

1. Release 附件里的 `banner-dark.png` / 其他 banner 图片；
2. Release 没有 banner 时，自动读取仓库对应 tag：

```text
https://raw.githubusercontent.com/username-xusir/nexusmc/<tag>/assets/updates/<版本>-dark.png
```

例如：

```text
https://raw.githubusercontent.com/username-xusir/nexusmc/v1.1.6/assets/updates/1.1.6-dark.png
```

这样即使发布时忘记上传横幅，只要仓库里提交了版本横幅，更新窗口也能显示。

## 验证

- 单元测试：80/80 通过（新增横幅兜底 URL 测试）。
- fixture 只包含安装包、没有 banner 资产时，返回的 `BannerUrl` 是正确的 raw GitHub 地址。
- 1.1.6 横幅已加入 `assets/updates/`。
- 安装包干净安装启动显示 1.1.6，卸载后安装目录完全删除。

## 保留

- 1.1.5 的深色主题、统一 18px 圆角、阴影代替描边和圆角滚动条。
- 1.1.3 的夸克 412 Cookie 刷新修复。
- 1.1.2 的更新检查缓存、ETag 和 403 / 429 提示。
- 1.1.1 的字体、启动器停用、自动 / 256 线程和布局修正。
