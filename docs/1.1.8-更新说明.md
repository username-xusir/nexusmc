# NEXMC 1.1.8 更新说明

1.1.8 统一安装结果窗口的卡片样式。

## 修复

安装结果里的启动器目标卡片原来还有一层淡色描边，和深色主题不一致。现在：

- 去掉 `BorderBrush` 描边；
- 卡片背景改为深色 `#1B1B1B`；
- 使用柔和阴影区分层次；
- 圆角统一为 18px。

## 验证

- 单元测试：80/80 通过。
- 安装结果窗口截图检查：目标卡片无浅色描边，圆角一致。
- 1.1.8 横幅已加入 `assets/updates/`。
- 安装包干净安装启动显示 1.1.8，卸载后安装目录完全删除。

## 保留

- 1.1.7 的深色代码块和状态栏修复。
- 1.1.6 的 Release 横幅 raw GitHub 兜底。
- 1.1.5 的深色主题、统一 18px 圆角、阴影代替描边和圆角滚动条。
- 1.1.3 的夸克 412 修复、1.1.2 的更新检查缓存。
