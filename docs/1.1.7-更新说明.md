# NEXMC 1.1.7 更新说明

1.1.7 修复深色主题下更新说明代码块白底白字的问题。

## 问题

更新窗口里的“产物”和 SHA-256 使用代码块渲染，但代码块背景还是浅色 `#F4F4F4`，文字跟随深色主题变成浅色，结果看起来像空白条。

## 修复

- 代码块背景改为深色 `#1B1B1B`。
- 代码块文字改为浅色，并显式使用正文颜色。
- 代码块圆角统一为 18px。
- 状态栏错误/普通状态的背景也从浅灰改为深色，避免底部突然出现浅色条。

## 保留

- 1.1.6 的 Release 横幅 raw GitHub 兜底。
- 1.1.5 的深色主题、统一 18px 圆角、阴影代替描边和圆角滚动条。
- 1.1.3 的夸克 412 Cookie 刷新修复。
- 1.1.2 的更新检查缓存、ETag 和 403 / 429 提示。

## 验证

- 单元测试：80/80 通过。
- 更新说明代码块在深色主题下可读。
- 1.1.7 横幅已加入 `assets/updates/`。
- 安装包干净安装启动显示 1.1.7，卸载后安装目录完全删除。
