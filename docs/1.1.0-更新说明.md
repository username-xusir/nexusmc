这次 1.1.0 不是把上一版说明换个版本号。它解决的是一个很具体的问题：BBSMC 上很多整合包只给网盘，以前 NEXMC 只能把链接丢给浏览器，后面的下载、解压、安装还是得自己来。现在，夸克和 UC 的分享链接可以留在 NEXMC 里处理。

## 先说结论

- 夸克 / UC 分享：能读文件列表，按你选的版本找到对应的 `.mrpack` / `.zip`，拿直链，下载，然后继续安装。
- 需要登录：自动弹出应用内登录窗口，登录后 Cookie 用 Windows DPAPI 加密保存在本机。
- 直链文件：直接下载，不经过网盘解析。
- 其他网盘：仍然识别类型，但暂时只打开浏览器。
- 名人堂新增 tidain；1.1.0 更新横幅换成新图。

## 网盘：从“打开浏览器”到“直接下载”

之前点“仅网盘”的版本，NEXMC 只能打开夸克或迅雷的分享页。这个流程没有错，但很断：你得自己看文件夹、找版本、点下载，再回来选本地包。

1.1.0 把夸克 / UC 这条链接了下来：

- 先读取分享凭证和文件列表；
- 如果分享里有很多版本，就按你当前选中的版本号去找对应的整合包；
- 找到 `.mrpack` / `.zip` 后获取下载直链；
- 下载进度、失败重试、取消都在 NEXMC 的任务里；
- 下载完成后直接走现有的本地整合包安装流程，PCL、HMCL、标准 `.minecraft` 都能继续用。

夸克游客状态只适合小文件。超过限制时服务端会返回 `23018`，NEXMC 不会绕过去，而是提示你登录。登录之后如果免转存取链失败，会回退到“临时转存 → 取链 → 下载完成后清理临时目录”。

百度、123、115、迅雷、蓝奏、139、光鸭这些目前只做了类型识别。点“打开网盘下载”仍然会打开原分享页，不会假装自己能解析。

## 登录：只在你需要的时候出现

这次没有把账号密码塞进 NEXMC。需要登录时，NEXMC 会打开一个应用内 WebView2 窗口，直接加载夸克 / UC 官方登录页；你在官方页面完成登录，然后点“我已登录，读取 Cookie”。

- Cookie 使用 Windows DPAPI 加密，保存在 `%LOCALAPPDATA%\NEXMC\netdisk-auth`；
- 不写进普通设置文件，不上传服务器；
- 设置页新增“网盘账号”，可以单独登录、重新登录、退出夸克和 UC；
- WebView2 起不来时，还有手动粘贴 Cookie 的兜底输入框。

## 名人堂：tidain

这次名人堂新增了 **tidain**，也就是云析 YunX-Desktop 的作者。

NEXMC 的网盘识别和直链解析是独立写的 C# 代码，没有复制云析的源代码、图标、名称或素材，也没有打包云析本体；但接口行为和错误码处理参考了云析的公开使用结果与公开抓包。这个参考值得在名人堂里写清楚。

- 卡片介绍：云析 YunX-Desktop 作者，网盘分享解析思路参考
- 链接：`https://github.com/tidain`
- 名人堂改成 2×2 布局，设置页头像条也加入了 tidain
- 1.1.0 更新横幅换成了新的版本图

## 还没做好的

- 登录后的真实大文件下载需要一个有效账号完成首次登录。本次测试没有使用真实账号 Cookie，所以登录态取链和转存回退只验证了接口和错误路径，没把 750MB 文件真正下完。
- 百度、123、115、迅雷、蓝奏等还没有自动取链。
- 安装包没有代码签名，Windows 可能显示“未知发布者”。

## 怎么用

1. 打开整合包列表，选一个网盘版本；
2. 如果按钮显示“解析网盘并安装”，直接点；
3. 需要登录时，在弹出的窗口里登录夸克 / UC，再点“我已登录，读取 Cookie”；
4. 下载完成后 NEXMC 会继续安装；只下载模式会保存到设置里的文件夹。
