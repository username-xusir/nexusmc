# NEXMC 1.0.7 更新说明

更新日期：2026-10-28

## 整合包界面重做

- 进入整合包页后自动加载全部整合包，不需要先点搜索；顶部可以直接切换来源和分类。
- 左侧是整合包名称列表；点开某个项目后直接进入版本管理，自动加载该项目的版本。
- 右侧详情显示封面、来源、下载量、简介和标签；版本列表在下方独立显示。
- 选择版本后点「下载并安装」，会先弹出命名窗口，让用户给这次下载的整合包起名；名称会作为 PCL/HMCL 的版本目录名。
- 「从本地安装」移到页面右上角；本地包路径、清除按钮固定在顶部，不再放在页面底部。
- 默认整合包搜索和版本加载都保留分页/加载更多，不会因为界面改动减少功能。

## 启动器修复

- 删除“标准 .minecraft（AppData）/ 用户目录 / 桌面”这类没有启动器程序的伪目标；不再显示“版本未知”的假启动器。
- 只有检测到真实启动器 EXE/JAR 时才自动加入列表；普通 `.minecraft` 目录必须通过「添加启动器」手动加入。
- 支持检测 HMCL 的 EXE 和 JAR；HMCL 版本优先从文件名读取（如 `HMCL-3.16.4`）。
- 同名启动器只显示「名称 · 已安装版本数量」，不再拼接本机目录名；旧版本残留的后缀重新扫描后会消失。
- 安装完成提示增加“重启 PCL/HMCL 刷新版本列表”，解决装完但启动器里暂时看不到的问题。
- 设置页提示当前未检测到 HMCL 时，引导用户把 HMCL 放到桌面/下载目录或手动添加。

## 下载与设置

- 保留「全部来源」、默认整合包来源、来源失败自动切换。
- 保留游戏下载线路、下载线程、限速、重试次数、重试间隔。
- 默认失败重试 3 次、每次 10 秒；失败后清理本次新建的未完成版本目录。
- CurseForge API Key 输入已移除，统一走 PCL 自带 MCIMirror。
- **自动线路改为优先官方源**：BMCLAPI 对新版本资源可能返回 404/302，旧逻辑会卡在 84% 左右；现在先走 Mojang，失败再回退镜像。想强制镜像可在设置里选择「镜像优先」。
- **增加无进度看门狗**：连续 180 秒没有进度会主动中断内核下载，按 3 次/10 秒策略重试，不再无限等待。

## 封面与布局

- 整合包封面改为异步加载，支持 PNG/JPEG 和 Modrinth 常用的 **WebP**（Imazen.WebP），失败时保留首字母占位；封面不会阻塞列表滚动。
- 封面按 URL 做磁盘缓存（`%LocalAppData%\NEXMC\IconCache`），重复进入页面不再重复下载。
- 修复长项目名把来源徽标、下载量、「查看版本」挤出屏幕的问题：列表项改为拉伸到可视宽度，长名称省略显示。
- 版本页封面和标题改为独立两列，长名称不会再压住封面图标。

## 仅网盘版本与验证

- 版本列表区分「直链可用」「仅网盘 · 可打开网盘」「仅网盘 · 无链接」。
- 选中仅网盘版本时，主按钮自动变为「打开网盘下载」；有网盘链接就打开夸克/迅雷等链接，没有网盘则打开项目介绍页。NEXMC 不绕过登录或人机验证。
- BBSMC 命中人机验证时**自动弹出内置 WebView2 验证窗口**，不需要再点错误提示里的按钮；即使其他启动器已经安装成功也会弹出。
- 版本加载、搜索等任意 BBSMC 请求命中验证时也会自动弹窗。
- 内置窗口完成验证并下载后，自动切换为本地整合包继续安装。

## 追加修复（2026-10-29）

- 整合包来源改为勾选式多选；可以取消 BBSMC，只查 Modrinth + CurseForge，也可以任意组合。慢来源仍按返回顺序逐步显示。
- 设置页新增「下载方式」：安装到启动器 / 仅下载到本地。整合包仅下载时保存 `.mrpack/.zip`；原版仅下载时生成可携带的本地 `.minecraft` 目录，不写入 PCL/HMCL。
- 任务完成后隐藏进度条，并在目标右侧显示绿色对勾；失败和取消不显示对勾。
- 启动器下拉框只显示「名称 · 已安装版本数量」，删除本机目录后缀和目录副标题；目录只放在悬停提示。
- 「添加启动器」的游戏目录改为可选；只选 EXE 时自动寻找 EXE 旁、用户目录或 EXE 旁的 `.minecraft`。
- 软件内改用透明背景的白色徽标（`badge-white.png`）：深色标题栏只剩白色轮廓和白色 N，不再有白底方块；桌面图标仍是白底黑标。
- 移除自动生成的目录后缀，代码中没有写死任何用户名或本机路径。
- 支持连续添加多个安装/下载任务：按钮不再被第一个任务锁死；任务进入队列，PCL 内核按顺序执行（内核安装引擎共享全局路径状态，真并发会互相覆盖），排队任务显示「排队中」。
- 每次切换到另一个整合包都会把实例名重置为该项目原名，不再沿用上一次改过的名字。
- 版本列表/搜索使用独立的元数据锁，不再被正在进行的安装阻塞；实测安装进行中加载另一个 BBSMC 项目的 63 个版本仅 4.1 秒。
- 「保存设置」不再等待安装释放内核锁；保存后立即显示“设置已保存，正在应用…”，按钮短暂变成“已保存 ✓”。实测安装进行中应用设置耗时 35 ms。
- 设置页新增「名人堂」鸣谢：左侧 huogoooo（内测）、中间 龙腾猫跃（PCL2 内核）、右侧 username-xusir（NEXMC 开发者）。点击 huogoooo 以外的两位头像会用默认浏览器打开爱发电/GitHub。

## 已知限制

- 第三方下载源/CDN 可能临时卡住；现在由 180 秒无进度看门狗中断并重试，但极端情况下 3 次仍可能失败，可切换来源或取消后重试。
- BBSMC 的封面 CDN（`cdn.bbsmc.net`）在部分网络下不可达，封面会显示首字母占位；这是网络可达性问题，不影响搜索、版本和安装。
- 安装后 PCL/HMCL 需要重启或刷新版本列表。
- 安装包未代码签名。
- PCL 作者单独许可凭证由维护者保存，不在仓库内公开。
