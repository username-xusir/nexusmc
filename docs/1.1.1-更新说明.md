# NEXMC 1.1.1 更新说明

1.1.1 是把 1.1.0 之后压着没发的东西一次放出来：字体、启动器停用、自动 / 256 线程、网盘快速分片路径，以及安装按钮和标题区的位置修正。

## 先说结论

- 界面字体换成 Noto Sans SC Medium，随安装包分发，不要求系统预装。
- 下载线程新增“自动（按速度调整，最高 256 线程）”，并支持 128 / 256 线程。
- 启动器可以停用，也可以一键恢复；停用项不会出现在安装目标下拉框。
- 网盘直链优先走快速分片多连接；Range 不可用或失败时自动回退 PCL2 多线程内核。
- PCL 内核支持网盘 CDN 需要的 Cookie、Referer、User-Agent。
- “创建安装实例”的开始安装按钮与输入框垂直对齐；四个页面的顶部标题区统一位置、高度和圆角。

## 字体：Noto Sans SC Medium

界面字体换成 Noto Sans SC Medium，随安装包一起分发，不依赖系统预装。图标字体仍然是 Segoe Fluent Icons / Segoe MDL2 Assets，Windows 10 的回退逻辑不变。

字体许可为 SIL Open Font License 1.1，全文在 `licenses/Noto-Sans-SC-OFL.txt`。

## 启动器：停用与恢复

设置页新增两个操作：

- **停用当前目标**：把顶部下拉框里当前选中的单个启动器从安装目标里隐藏，不删除游戏目录、不修改启动器文件；
- **恢复已停用**：一次性把所有停用的启动器恢复回来。

“全部已识别启动器”不能一键停用，必须先选择一个单独的启动器。停用状态写进本机设置，重启后仍然有效。

## 线程：自动 / 最高 256

下载线程下拉框新增：

- **自动（按速度调整，最高 256 线程）**
- 128 线程
- 256 线程

自动模式会先做 4 路小范围测速，再按速度选择连接数；下载过程中快速分片路径按实测吞吐量分配 4MB 分片。PCL2 回退路径的上限也提高到 256，不再卡在 64。

## 网盘：两条下载路径

1.1.0 已经能把夸克 / UC 分享解析成直链。1.1.1 在直链之后加了一条快速路径：

- 先探测服务器是否支持 Range；
- 支持时按 4MB 分片、多连接并行写入预分配文件；
- 自动线程模式按实测速度决定连接数；
- 服务器不支持 Range、返回整文件或快速路径失败时，自动回退 PCL2 多线程内核；
- 两条路径都会携带网盘 CDN 需要的 Cookie、Referer、User-Agent。

下载进度、失败重试、取消和完成后的临时目录清理仍然在 NEXMC 的任务里。

## 界面：按钮和标题区

这次改了两个很具体的位置问题：

- “创建安装实例”卡片里，`开始安装` 按钮原来贴在名称输入框右下角；现在按钮与输入框同一行垂直居中，中间保留 16px 间距。
- 游戏下载、整合包、下载任务、设置四个页面的顶部标题区，原来整合包页的上下边距和另外三页不一致；现在统一为相同高度、相同内边距和 18px 圆角。

截图测量结果：四个标题区的左右边界均为 56–2008px，上下边界均为 151–402px；安装按钮与输入框中心线均为 1123.5px。

## 保留的 1.1.0 功能

- 夸克 / UC 分享自动解析，按版本号选择对应整合包；
- 应用内 WebView2 登录，Cookie 使用 Windows DPAPI 加密保存在本机；
- 网盘账号单独登录 / 退出；
- BBSMC 人机验证窗口和验证后自动续装；
- 自动更新、更新弹窗和 1.1.0 横幅；
- 名人堂中的 tidain 鸣谢。

## 我实际测了什么

- 单元测试：75/75 通过。
- 快速分片路径：20MB 文件、单连接限速 512KB/s 的本地服务器，PCL 内核单线程约 46 秒，快速路径约 14 秒。
- 快速分片回退：服务器忽略 Range 时返回 `FAST_DOWNLOAD=fallback`，由 PCL2 内核接手。
- PCL 自定义请求头：本地测试服务器要求 Cookie / Referer / User-Agent 全部匹配，PCL 内核下载 3,158,073 字节，全部请求头校验通过。
- 字体：安装后截图确认 Noto Sans SC Medium 已应用。
- 下载线程：UI Automation 读到 7 个选项：自动、8、16、32、64、128、256。
- 布局：四个页面标题区边界一致；输入框与按钮中心线对齐。
- 安装包：干净安装启动显示 1.1.1，卸载后安装目录文件数为 0。

## 还没做好的

- 登录后的真实大文件下载需要一个有效账号完成首次登录；本次没有使用真实账号 Cookie，所以登录态取链和转存回退只验证了接口和错误路径。
- 百度、123、115、迅雷、蓝奏等还没有自动取链，仍然使用“打开网盘下载”。
- 安装包没有代码签名，Windows 可能显示“未知发布者”。

## 怎么用

1. 运行 `NEXMC-Setup-1.1.1.exe` 安装；
2. 在顶部选择安装目标，或点 `+` 添加启动器；
3. 游戏下载页选择版本和加载器，点“开始安装”；
4. 网盘版本需要登录时，在弹出的窗口里登录夸克 / UC，再继续；
5. 设置页可以切换自动 / 128 / 256 线程、停用启动器、查看名人堂。
